# 明日香双形态 Pets

两套独立宠物：明日香·校服、明日香·战斗服。各套包含九种标准动画和十六个注视方向。

## 启用与切换

1. 在当前 Codex 桌面应用打开“设置 → Pets”。
2. 点击 Refresh／刷新，使应用重新扫描本地宠物包。
3. 选择“明日香·校服”作为日常形态，或选择“明日香·战斗服”作为工作形态。
4. 通过 `/pet` 或 Show pet 显示浮动宠物；如果系统启用了减少动态效果，请检查该设置，否则可能只显示静帧。
5. 以后仍在同一个选择器切换两套形态。要恢复旧宠物，选回“白龙司书”。

当前采用官方 hatch-pet 本地包机制，安装目标分别为：

- `C:\Users\86191\.codex\pets\asuka-school\`
- `C:\Users\86191\.codex\pets\asuka-work\`

每套仅需 `pet.json` 与 `spritesheet.webp`，清单声明 `spriteVersionNumber: 2`。安装与本机显示验收的实际状态见项目 `docs/07-最终接入与验收报告_工作稿.md`。

## 能力边界

两套服装通过选择宠物手动切换。未找到已验证的官方自定义服装切换接口，当前不承诺按任务状态自动换装。各套内部均有完整状态行；本机状态触发是否正常，需要应用实际播放确认。

图集为1536×2288，单格192×208，各行帧数6/8/8/4/5/8/6/6/6/8/8，共73个有效帧，15个空格透明。

战斗服注视两行之间发梢宽度略变，已通过独立审阅，保留为轻微观感问题。部分侧面移动帧的02标识较小且被遮挡，未发现反字，不能保证每帧都清晰可读。
