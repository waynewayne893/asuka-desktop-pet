# 03-状态与台词设计表

## 一、状态设计总表

### A. 日常形态（校服）
1. **待机**：普通看向前方，轻微傲娇感
2. **开心**：露出得意或轻松微笑
3. **发呆**：无聊、闲置、等用户操作
4. **生气 / 催促**：提醒用户别摸鱼、该继续工作了
5. **提示 / 对话**：适合弹出气泡，回答或提醒

### B. 工作形态（白色战斗服）
1. **专注**：任务开始前或运行初期
2. **思考**：分析、推理、处理中
3. **执行中**：明确工作状态
4. **报错 / 不满**：出错、失败、卡住
5. **完成 / 得意**：任务成功完成

## 二、台词风格原则
- 语气：自信、傲娇、直接、可靠
- 不能过分恶毒
- 不能完全软萌
- 以“催促你做事，但其实是在帮你”为核心气质

## 三、示例台词
### 日常形态
- 待机：`我可没在等你。`
- 开心：`还行嘛。`
- 发呆：`……你到底还开不开工？`
- 生气 / 催促：`别摸鱼了，快继续。`
- 提示：`有问题就说。`

### 工作形态
- 专注：`任务开始，集中精神。`
- 思考：`先分析一下。`
- 执行中：`别打断我。`
- 报错 / 不满：`这里出错了，先定位原因。`
- 完成 / 得意：`看吧，还是做到了。`

## 四、Codex 场景映射建议
- 空闲 / 无任务 -> 日常待机
- 用户点击 / 简单互动 -> 日常提示或开心
- 长时间无操作 -> 日常发呆 / 催促
- 任务启动 -> 工作专注
- 处理中 -> 工作思考 / 执行中
- 错误 / 失败 -> 工作报错
- 成功完成 -> 工作完成（或完成后切回日常开心）
