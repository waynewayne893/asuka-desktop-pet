# 02-美术规格书

## 1. 总体风格
- 精致 Q 版，小型角色素材
- 约 **3.5 头身**
- 不是极端幼态，不是普通大立绘
- 保持原作明日香的识别度与气质

## 2. 角色一致性要求
以下内容必须在双形态中一致：
- 脸型基础
- 眼睛形状与蓝色瞳色
- 橙红色长发
- 双侧红色发饰
- 明日香的自信、傲娇、略挑眉的气质
- 骨架基准与四肢长度逻辑

## 3. 日常形态（校服）
### 保留元素
- 白色上衣
- 红色领结
- 蓝色/青蓝色校服裙装结构
- 长袜 / 白袜
- 深色皮鞋

### 气质目标
- 日常、陪伴、轻松
- 可以略带不耐烦，但整体更柔和

## 4. 工作形态（白色战斗服）
### 保留元素
- 白色主体
- 红色结构线
- 蓝色腿部与侧边细节
- `02` 标识
- 一体化紧身战斗服轮廓

### 核心要求（非常重要）
- 特别重视原作 **腰—臀—腿的自然连续曲线**
- 腿部必须修长、有结构，不能过短
- 关节（髋、膝、踝）要清晰可读
- 臀部不能鼓包、不能像尿布感短裤
- 白色战斗服要贴合身体，而不是一团圆鼓鼓的白色块面

## 6. 输出建议
第一轮扩展素材建议：
- 每个形态先做 5 个基础状态
- 优先透明背景 PNG
- 同一画布尺寸
- 角色落点与基线尽量统一，便于后期切换
