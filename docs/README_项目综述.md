# README_项目综述

## 一、项目定位
本项目要做的不是独立 Windows 桌宠海报，也不是随意生成的一组贴纸形象，而是一个准备交由 **Codex** 继续实现的“明日香虚拟宠物”设计与实现方案。

目标角色：**明日香**

目标风格：**精致 Q 版 / 小型角色素材 / 约 3.5 头身**

目标用途：用于 Codex 中的虚拟宠物、陪伴助手、状态反馈角色。

## 二、双形态定义
### A. 日常形态（校服）
- 来源：TV / 剧场版的经典校服印象
- 功能：陪伴、待机、提示、聊天、休息
- 视觉特点：轻松、自然、日常感强

### B. 工作形态（白色战斗服）
- 来源：《新·福音战士剧场版：终》白色战斗服
- 功能：任务开始、执行中、思考、报错、完成
- 视觉特点：专注、执行感、工作模式

## 三、已经达成的关键审美结论
1. 不使用过低头身比的萌化比例。
2. 工作形态必须保留原作明日香优雅、协调的腰臀腿比例。
3. 白色战斗服必须看起来像紧身且贴合人体的战斗服，而不是圆鼓鼓的团块。
4. 校服版与工作版必须共享同一角色骨架和脸型，不得风格漂移。
5. 当前认可的两张基准图见 `references/approved_baselines/`。

## 四、推荐的后续产出顺序
1. 验证 Codex 当前版本可支持的宠物/动画资产接入能力。
2. 以两张基准图为母版，扩展状态动作。
3. 先做“站姿/待机/思考/执行/报错/完成”核心状态。
4. 再整理为 Codex 实际需要的产物格式（例如 sprite sheet、独立透明 PNG 或其他官方支持的格式）。
5. 最后再接入、调试、验收。
