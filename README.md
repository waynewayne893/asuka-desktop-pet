# Codex 明日香双形态虚拟宠物交付包 v2

本交付包用于在 **Codex** 中继续推进“明日香双形态虚拟宠物”项目。

## 项目目标
制作一个适用于 Codex 的内置/官方可支持的虚拟宠物，角色为 **明日香**，采用 **精致 Q 版（约 3.5 头身）** 风格，并具有两种主要形态：

1. **日常形态（校服）**
2. **工作形态（《终》白色战斗服）**

## 当前结论（已经由用户确认）
- 不采用过低头身比的幼态 Q 版。
- 采用 **约 3.5 头身** 的精致小型角色风格。
- **工作形态**必须特别保留原作中自然协调的 **腰—臀—腿连续曲线**，避免臀胯拥挤、尿布感、腿部过短或臃肿。
- **校服形态**与工作形态必须共享同一套人物骨架、脸型、发型逻辑和气质，看起来像“同一个明日香换装”，而不是两个不同小人。
- 用户已经认可本包 `references/approved_baselines/` 中的两张基准图，后续设计应优先以它们为母版。

## 建议给 Codex 的工作顺序
1. 先阅读 `docs/` 里的全部说明。
2. 核对当前 Codex 版本是否支持官方 Pets / 宠物 / hatch-pet / 自定义 sprite 工作流（**先核实，不要假设支持**）。
3. 以 `references/approved_baselines/` 中的两张图为美术母版。
4. 先做动作与状态规划，再决定 sprite sheet / 独立 PNG / 透明背景素材的产出方式。
5. 若官方工作流可行，再推进动画素材生产与接入；若不可行，再提出替代方案，但不要擅自修改安装文件或走高风险注入方案。
